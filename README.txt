# Kashish Bassi — Professional Resume Portfolio

## Files
- `index.html` — main website
- `style.css` — complete responsive design
- `script.js` — mobile menu, scroll reveal and current year
- `assets/profile.jpg` — supplied profile photo
- `assets/favicon.svg` — site favicon
- `Kashish-Bassi-Resume.pdf` — supplied resume

## How to use
Open `index.html` in a browser to preview the website.

The site uses no frameworks or external libraries, so it is easy to host on GitHub Pages, Netlify or another static hosting service.
